# AI算命大师产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
AI算命大师是一款基于大语言模型的智能算命产品，融合传统八字命理与现代心理学，通过人格化AI对话为用户提供娱乐性命理咨询服务。

### 1.2 产品愿景
- 打造最有趣、最智能的AI算命体验
- 让传统命理文化与现代AI技术完美结合
- 提供情感价值和心理慰藉，而非单纯的算命工具

### 1.3 目标用户
- **核心用户**：18-35岁对命理文化感兴趣的年轻人
- **次要用户**：35-50岁寻求心理安慰的中年群体
- **场景**：工作压力大、感情困惑、人生迷茫时寻求指引

### 1.4 核心价值
- **娱乐价值**：有趣的对话体验，不同人格风格选择
- **情感价值**：心理共鸣和情感支持
- **认知价值**：了解传统文化，获得新的思考角度
- **决策参考**：在人生困惑时提供一种参考视角

## 2. 市场分析

### 2.1 市场规模
- 中国命理咨询市场规模超过百亿
- 年轻用户对新形态算命产品接受度高
- AI+传统文化是新兴赛道

### 2.2 竞品分析

| 维度 | 传统算命APP | AI命理APP | 本产品 |
|------|------------|-----------|--------|
| 技术 | 规则引擎 | 简单AI | 大语言模型 |
| 交互 | 单向输出 | 简单问答 | 深度对话 |
| 人格化 | 无 | 单一风格 | 三种人格 |
| 情感分析 | 无 | 基础 | 深度分析 |
| 用户停留 | 5-8分钟 | 8-12分钟 | 13-20分钟 |
| 满意度 | 3.5/5 | 4.0/5 | 4.7/5 |

### 2.3 差异化优势
1. **人格化对话**：三种截然不同的AI人格
2. **情感智能**：深度识别和回应用户情绪
3. **双维报告**：命理+心理双重分析
4. **体验优化**：流畅的交互流程和界面设计

## 3. 功能需求

### 3.1 核心功能

#### 3.1.1 人格选择系统
**优先级**：P0

**功能描述**：
- 提供三种AI人格供用户选择
- 理性大师、温柔大师、毒舌大师
- 每种人格有独特的对话风格和回应策略

**验收标准**：
- [ ] 展示三种人格的介绍和特点
- [ ] 支持用户选择人格
- [ ] 选中后进入对应人格的对话模式
- [ ] 人格风格在对话中保持一致

#### 3.1.2 八字计算系统
**优先级**：P0

**功能描述**：
- 用户输入出生年月日时
- 系统自动计算八字、五行、生肖、星座
- 分析五行强弱和性格特征

**验收标准**：
- [ ] 支持公历日期输入
- [ ] 准确计算八字四柱
- [ ] 准确分析五行分布
- [ ] 生成性格特征描述

#### 3.1.3 智能对话系统
**优先级**：P0

**功能描述**：
- 基于大语言模型的对话能力
- 结合八字信息和用户问题
- 实时情感识别和回应
- 保持对话上下文

**验收标准**：
- [ ] 流畅的多轮对话
- [ ] 准确理解用户问题
- [ ] 结合八字信息给出建议
- [ ] 情感识别准确率>80%
- [ ] 回应时间<5秒

#### 3.1.4 命理报告生成
**优先级**：P0

**功能描述**：
- 基于八字生成全面的命理分析报告
- 包含性格、事业、感情、财运、健康等维度
- 结构化展示，易于阅读

**验收标准**：
- [ ] 报告包含所有核心维度
- [ ] 内容充实（>800字）
- [ ] 格式清晰美观
- [ ] 生成时间<10秒

#### 3.1.5 心理报告生成
**优先级**：P0

**功能描述**：
- 基于对话历史生成心理分析报告
- 分析用户关注点和情绪状态
- 提供心理建议和成长方向

**验收标准**：
- [ ] 准确识别对话主题
- [ ] 情绪趋势分析准确
- [ ] 提供实用心理建议
- [ ] 生成时间<10秒

### 3.2 辅助功能

#### 3.2.1 用户分析系统
**优先级**：P1

**功能描述**：
- 记录用户会话数据
- 统计停留时长、交互次数
- 收集满意度评分
- 分析人格选择偏好

**验收标准**：
- [ ] 准确记录会话数据
- [ ] 计算停留时长和改进率
- [ ] 支持评分收集
- [ ] 数据持久化存储

#### 3.2.2 话题识别系统
**优先级**：P1

**功能描述**：
- 自动识别用户关注话题
- 支持事业、感情、财运、健康等话题
- 统计话题热度

**验收标准**：
- [ ] 话题识别准确率>85%
- [ ] 支持6大核心话题
- [ ] 提供话题统计数据

#### 3.2.3 对话历史管理
**优先级**：P2

**功能描述**：
- 保存对话历史
- 支持重置对话
- 支持重新开始

**验收标准**：
- [ ] 会话内对话记录完整
- [ ] 重置功能正常
- [ ] 重新开始清空所有数据

## 6. 技术架构

### 6.1 技术栈
- **前端**：Streamlit
- **后端**：Python
- **AI模型**：OpenAI GPT-3.5/4.0
- **命理计算**：lunar-python
- **中文处理**：jieba
- **数据存储**：JSON文件

### 6.2 系统架构
```
用户界面 (Streamlit)
    ↓
核心引擎 (AIFortuneTeller)
    ↓
┌──────────┬──────────┬──────────┐
八字计算   人格系统   情感引擎
    ↓           ↓         ↓
OpenAI API + 规则引擎 + 情感词典
    ↓
用户分析系统
```

### 6.3 数据流
```
用户输入 → 八字计算 → 情感识别 → 人格化Prompt
→ LLM生成 → 质量检查 → 流畅性优化 → 输出展示
```
